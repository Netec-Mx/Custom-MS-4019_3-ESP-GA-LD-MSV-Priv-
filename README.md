# Transformación de los procesos empresariales cotidianos con agentes: Construye y gestiona un agente

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Transformación de los procesos empresariales cotidianos con agentes: Construye y gestiona un agente**.

Aquí podrás desarrollar habilidades prácticas en la creación, configuración y administración de agentes en SharePoint, utilizando Microsoft 365 Copilot para optimizar la revisión de solicitudes internas de servicios tecnológicos y operativos.


## Lista de laboratorios

Cada laboratorio está diseñado para ofrecerte una experiencia práctica mediante escenarios empresariales. Haz clic en el enlace para comenzar.

### [Práctica 1. Creación de un agente de SharePoint](Capitulo01/README.md)

- **Descripción:** Crearás y configurarás un agente de SharePoint especializado en la revisión de solicitudes internas de servicios tecnológicos y operativos. Incorporarás procedimientos, políticas, requisitos y responsabilidades como fuentes de conocimiento. Posteriormente, probarás el agente con tres solicitudes simuladas: una completa, otra con documentación faltante y una tercera con inconsistencias. Finalmente, ajustarás sus instrucciones, comprobarás su funcionamiento desde Microsoft 365 Copilot y explorarás las opciones para compartirlo y administrarlo.

- ⏱️ **Duración estimada:** 80 minutos.
